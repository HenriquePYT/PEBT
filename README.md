# Personal Expense and Budget Tracker (PEBT)

A clean, efficient Python-based budget tracking application designed to help users track daily expenses, monitor spending against a preset budget limit, and manage records through an interactive command-line interface[cite: 1].

## Features
- **Dynamic Expense Logging:** Add expenses with detailed records including month, day, category, and price stored in a list of tuples[cite: 1].
- **Budget Management:** Real-time calculation of remaining budget and tracking total expenses on the fly, complete with warning alerts if spending exceeds your limit[cite: 1].
- **Safe Expense Management:** Built-in error handling and safe deletion logic using 1-based user indexing mapped to 0-based internal operations[cite: 1].
- **Interactive CLI:** Easy-to-use command-line interface with robust input validation to prevent crashes from unexpected text inputs[cite: 1].

## Built With
- **Language:** Python 3[cite: 1]
